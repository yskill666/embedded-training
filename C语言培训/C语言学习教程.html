认识 C 语言

WHAT IS C

C 语言是 1972 年由丹尼斯·里奇（Dennis Ritchie）在贝尔实验室为重写 UNIX 而设计的语言：面向过程、编译型、静态类型。它既有高级语言的语法，又能像汇编一样直接操作内存。

特点与战场
特点说明
高效编译后直接生成机器码，运行速度接近汇编
贴近硬件指针直接访问内存地址，适合驱动与嵌入式
可移植同一份代码，不同平台重新编译即可运行
语法精炼关键字只有几十个，核心语法一周可学完
信任程序员不做多余检查——权力大，责任也大

主战场：操作系统内核、嵌入式 / 单片机（STM32、51、ESP32）、驱动、编译器。Python 官方解释器 CPython、Git、Redis 都是 C 写的。标准演进 C89 → C99 → C11 → C17 → C23，本教程兼容 C99 及以上，MinGW-w64 全部支持。

程序是怎么跑起来的
hello.c 预处理 · 编译 汇编 · 链接 hello.exe
BASH — 一条命令完成四步
gcc hello.c -o hello

第一个 C 程序与 main 函数

HELLO, C
hello.c
#include <stdio.h>

int main(void)
{
    printf("Hello, C!\n");
    return 0;
}
代码含义
#include <stdio.h>包含标准输入输出头文件，因为要用 printf
int main(void)主函数：程序入口；int 是返回值类型，void 表示不接收参数
{ }函数体边界，所有语句写在花括号内
printf(...);向屏幕打印内容，\n 是换行
return 0;向操作系统返回 0，表示程序正常退出
main 函数三条铁律
  • 入口性：程序从 main 第一行开始，到 main 结束而结束。
  • 唯一性：一个工程有且只有一个 main 函数。
  • 标准写法：int main(void) 或 int main(int argc, char *argv[])。void main() 不符合标准，考试和工作都不要写。
注意　新手高频错误：漏分号、中文标点（； “”）、stdio 拼成 studio、main 拼成 mian、花括号不配对。报错先查这五项。

03.

printf 与 scanf

I / O
printf：格式化输出
printf.c
printf("整数：%d，小数：%f，字符：%c\n", 100, 3.14, 'A');
// 输出：整数：100，小数：3.140000，字符：A
占位符含义示例
%d / %u十进制整数 / 无符号整数printf("%d", 42);
%c / %s单个字符 / 字符串printf("%s", "abc");
%f小数；%.2f 保留两位printf("%.2f", 3.14159); → 3.14
%p / %x / %o地址 / 十六进制 / 八进制printf("%x", 255); → ff
%%打印 % 本身printf("100%%");
scanf：格式化输入
scanf.c — 变量前必须加 &
int age;
scanf("%d", &age);   // 把输入的整数存进 age 的地址
printf("你今年 %d 岁\n", age);
注意　double 输入要用 %lf：scanf("%lf", &height);，输出用 %f 即可——新手高频考点。
  • 漏写 &：程序崩溃或行为异常。
  • %c 会吃掉上次输入残留的回车，写成 " %c"（前置空格）跳过空白。
  • scanf 返回成功读入的项数，可用来校验输入；格式串末尾不要加 \n。
sum.c — 输入两个数求和
#include <stdio.h>
int main(void)
{
    int a, b;
    printf("请输入两个整数：");
    scanf("%d %d", &a, &b);
    printf("%d + %d = %d\n", a, b, a + b);
    return 0;
}

04.

注释：写给人看的代码

COMMENTS

编译器完全忽略注释。注释写给三种人看：队友、三个月后的自己、审查代码的老师。嵌入式项目维护数年，没有注释的代码等于一次性代码。

两种写法
// 单行注释：从 // 到本行结束（最常用）

/* 多行注释：可以跨行
   注意：不能嵌套！ */
规范：解释"为什么"，不翻译代码
坏注释 vs 好注释
i = i + 1;  // 坏：把 i 加 1（废话，毫无信息量）
i = i + 1;  // 好：跳过帧头，指向数据区第一个字节
  • 文件开头写：用途、作者、日期；函数开头写：功能、参数、返回值。
  • 关键算法、反直觉写法、临时方案（TODO / FIXME）必须注释。
  • 改了代码记得同步改注释——过时的注释比没有注释更害人。

生命周期与作用域

LIFETIME & SCOPE
概念维度含义
作用域空间这个名字在哪些代码区域可见
生命周期时间这块内存从创建到销毁存活多久
变量作用域生命周期存储区
局部变量所在 { } 内进块创建，出块销毁栈区

同名时局部优先
int x = 100;          // 全局

sizeof 与类型长度

SIZEOF

sizeof 是操作符，不是函数：计算类型或变量占用的字节数，结果类型是 size_t，用 %zu 打印，编译期就确定。

三种用法
printf("%zu\n", sizeof(int));   // 类型：必须带括号 → 4
int a = 10;
printf("%zu\n", sizeof a);      // 变量：括号可省略 → 4
printf("%zu\n", sizeof(a + 1)); // 表达式：按结果类型算 → 4
类型字节类型字节
char1float4
short2double8
int / long4long long8
指针（任意类型）8Linux 64 位的 long8
两个细节　① sizeof 内的表达式不求值：sizeof(a++) 不会真的让 a 加 1。② 数组元素个数 = sizeof(arr) / sizeof(arr[0])，学到数组时的标准写法。跨平台代码不要假设长度。

signed、unsigned 与取值范围

SIGNED / UNSIGNED

整数以二进制存储，最高位是符号位：0 正 1 负。signed 可正可负（int 默认就是 signed int）；unsigned 所有位都表示数值，只能非负，但正数范围翻倍。

类型signed 范围unsigned 范围
char（1 字节）−128 ～ 1270 ～ 255
short（2 字节）−32768 ～ 327670 ～ 65535
int（4 字节）约 ±21.4 亿0 ～ 约 42.9 亿
long long（8 字节）约 ±9.2×10¹⁸0 ～ 约 1.8×10¹⁹

公式：n 位时 signed 为 −2ⁿ⁻¹ ～ 2ⁿ⁻¹−1，unsigned 为 0 ～ 2ⁿ−1。

溢出回绕

c = c + 1;
printf("%u\n", c);   // 0：无符号溢出"回绕"，标准保证
注意　char d = 127; d + 1 在多数平台得 −128，但有符号溢出是未定义行为，必须避免。打印 unsigned 用 %u；范围常量在 <limits.h>：INT_MAX、INT_MIN、UCHAR_MAX，不用背数字。

字符类型 char 与 ASCII 编码

CHAR & ASCII

char 占 1 字节，本质是整数：字符 'A' 在内存里就是数字 65。ASCII 表规定了 0–127 号编码与字符的对应关系。

同一块内存，两种解读
char c = 'A';
printf("%c\n", c);   // A：按字符解读
printf("%d\n", c);   // 65：按整数解读
记忆方法：三个锚点 + 两条规律
锚点编码规律
'0'48数字连续：'5' = 48 + 5 = 53
'A'65字母连续：'C' = 65 + 2 = 67
'a'97大小写差 32：'a' − 'A' = 32
ASCII CODE65

输入任意字符，实时查看编码
空格 = 32，换行 = 10

字符运算实战
char lower = 'g';
char upper = lower - 32;   // 'G'，也可写 lower - 'a' + 'A'

char digit = '7';
int num = digit - '0';      // 7，不是 55！字符转数字标准手法
注意　'7' 和 7 完全不同：前者是编码 55 的字符，后者是整数 7。digit − '0' 是嵌入式解析协议的常用手法。

13.

字符串与 \0

STRINGS & \0

C 语言没有字符串类型，用双引号字面量和字符数组表示。"hello" 实际占 6 字节：h e l l o \0——末尾的 \0 是编译器自动添加的结束标志，所有字符串函数靠它判断"到此为止"。

两种初始化的关键区别
char arr1[] = "abc";            // a b c \0 → 4 字节
char arr2[] = {'a', 'b', 'c'};  // a b c → 3 字节，没有 \0！

printf("%s\n", arr1);   // 正常输出 abc
printf("%s\n", arr2);   // 越界读取：abc 后跟乱码，直到偶遇 \0
对比含义"abc" 存于数组
strlen有效长度，读到 \0 为止，不含 \0（库函数，需 string.h）3
sizeof内存占用字节数，含 \0（操作符，无需头文件）4
%s 的工作原理：遇到 \0 停止
char s[] = "ab\0cd";
printf("%s\n", s);          // ab：中间的 \0 提前终止
printf("%zu\n", strlen(s)); // 2
printf("%zu\n", sizeof(s)); // 6：a b \0 c d \0
注意　手动逐字符初始化字符串时，记得自己补 \0：{'a','b','c','\0'}。

{

    int scores[MAX_STU] = {0};     /* 成绩 */
    int classes[MAX_STU] = {0};    /* 班级 */

    int isTeacher = 0;             /* 权限标志 */
    int choice;

    /* 密码登录：3 次机会，输 0 以学生身份跳过 */
    for (int i = 0; i < 3; i++)
    {
        int pwd;

        }
    } while (choice != 0);
    return 0;
