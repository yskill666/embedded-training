MODULE 02

文件资源管理：目录、路径与后缀

目录=文件夹，是一棵倒过来的树；路径是地址；后缀告诉系统文件类型。下面这张"资源管理器"卡牌可以点：左树切换目录、右列表点文件看后缀，还能开关"隐藏后缀"体验双后缀陷阱。

📁C:\Users\Admin\Desktop\suite资源管理器
点一个文件查看它的后缀与类型。

概念目录 / 路径 / 后缀

术语含义例子
目录 / 文件夹装文件和其它文件夹的容器Desktop\suite
根目录 / 盘符一个盘的最顶层起点C:\
父 / 子目录上一层 / 下一层Desktop 是 suite 的父目录
绝对路径从盘符写全的地址C:\Users\Admin\Desktop\suite\index.html
相对路径以当前目录为起点..\c\index.html
. 与 ..当前目录 / 上一级目录cd ..
后缀 / 扩展名最后一个点后的部分，决定类型与打开方式index.html → html
安全：打开"显示文件扩展名"（Win11：查看→显示→文件扩展名；Win10：查看→勾选文件扩展名）。否则 病毒.jpg.exe 会伪装成 病毒.jpg。改后缀不会改变文件内容，乱改只会让系统不知用什么打开。

速查常见后缀

后缀类型后缀类型
.txt / .md纯文本 / Markdown.jpg / .png / .svg图片
.html / .css / .js网页.mp3 / .mp4音频 / 视频
.c / .h / .py源码.pdf便携文档
.exe / .msi / .bat可执行 / 安装 / 脚本.docx / .xlsx / .pptxOffice
.zip / .7z / .rar压缩包.json / .csv / .lnk数据 / 快捷方式

终端入门：简易 CMD 指令

终端=用打字代替鼠标指挥电脑。下面是一个安全沙盒模拟 CMD，真的可以敲命令练手，不会动你真实文件。真机打开方式：Win+R → 输入 cmd → 回车。

CMD 沙盒 · 练习用

必会基础命令

命令作用命令作用
dir列当前目录type 文件看文本内容
cd 目录 / cd ..进入 / 回上一级cls清屏

MODULE 04

GitHub 访问与合法加速

国内直连 GitHub 常转圈/超时，是链路问题不是电脑坏。推荐开源免费的 Watt Toolkit（原 Steam++）做本地择优加速。

推荐Watt Toolkit（原 Steam++）

开源免费本地反向代理工具箱：在本机起代理、自动挑当前网络下最优节点转发，从而正常打开 GitHub。官网 steampp.net，开源仓库 BeyondDimension/SteamTools，微软商店搜 "Watt Toolkit" 也可。

步操作
1官网 / 微软商店 / 官方 Releases 下载安装
2打开 → 左侧"网络加速"
3勾选 GitHub → 点"一键加速"
4按指引信任本地证书（本地代理所需）
5访问 github.com 正常打开即成功；clone 变快
6不用时点"停止加速"
合规边界：只做正常访问加速，遵守法律与网站条款；只从官方渠道下载；不用时停止加速并可移除本地证书。加速≠法外之地。

备选其它思路（了解）

改 hosts 把域名指向可用 IP（需维护、易失效）；换公共 DNS 如 223.5.5.5 / 119.29.29.29 缓解 DNS 污染；克隆慢可考虑可信镜像。新手优先 Watt Toolkit 图形化最省事。

MODULE 05

国内 AI 工具与智能体（Agent）

对话模型是"一问一答"；智能体是"交一项任务，它自己规划→调工具→多步执行→给结果"。先会用对话，再逛智能体广场。

对话几大 AI 官网

边界：AI 会幻觉，关键结论自己验证；学 C 先自己写再对照 AI，别直接抄；不要把密码 / token / 隐私贴给 AI。

Agent智能体平台

先逛广场挑现成的（翻译 / PPT / 代码审查 / 文献总结）直接用；有兴趣再到 Coze / 文心智能体自己搭一个，比如"电控组新生答疑助手"。

CHECKLIST

结业自查清单

  • 能盲按 Ctrl+C/V/X/Z/S/A/F 与 Alt+Tab、Win+E、Win+Shift+S。
  • 能说出目录/父目录/根目录/绝对路径/相对路径，看懂 ..。
  • 已打开"显示文件扩展名"，认全常见后缀，知道双后缀陷阱。
  • 会在 CMD 里 dir / cd / mkdir / echo / cls，知道删除不可逆。
  • 会用 Watt Toolkit 合法加速 GitHub，只从官方渠道下载。
  • 至少用过 2 个 AI 官网 + 1 个智能体广场，知道幻觉与隐私边界。
