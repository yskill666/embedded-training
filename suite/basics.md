## 模块一 · 键盘与常用快捷键

### 1.1 为什么要练快捷键

鼠标点十次，键盘一次到位。快捷键不是"炫技"，而是把重复动作变成肌肉记忆，
后面写代码、改文档、管文件都会快一个量级。先认键位，再练组合。

### 1.2 认识修饰键

- **Ctrl**（Control）：最常用的"组合键老大"，配合字母完成编辑操作。
- **Shift**：上档键。单独按配合方向键=选中；配合字母=大写/上符号。
- **Alt**（Alternate）：切换/菜单类组合。
- **Win**（Windows 徽标键）：系统级组合（桌面、资源管理器、锁屏、截图）。
- **Esc**：取消/退出当前操作。
- **Tab**：跳格/切换焦点；写代码时缩进。

组合键写法 `Ctrl + C` 表示：**先按住 Ctrl 不放，再按一下 C，然后一起松开**。

### 1.3 编辑类（最高频，先练熟）

| 快捷键 | 作用 |
| --- | --- |
| Ctrl + C | 复制 |
| Ctrl + V | 粘贴 |

### 1.4 窗口与系统类

## 模块二 · 文件资源管理：目录、路径与后缀

### 2.1 什么是目录（文件夹）

**目录 = 文件夹**，是用来装文件和其它文件夹的"容器"。整棵结构像一棵倒过来的树：

```
C:\                      ← 根目录（盘符起点）
└─ Users\
   └─ Admin\
      ├─ Desktop\        ← 桌面
      │  └─ suite\       ← 一个目录（文件夹）
      │     ├─ index.html
      │     └─ git.html
      └─ Documents\      ← 文档
```

- **盘符**：`C:`、`D:` 是不同磁盘分区的起点。
- **根目录**：一个盘的最顶层，如 `C:\`。
- **父目录 / 子目录**：`Desktop` 是 `suite` 的父目录；`suite` 是 `Desktop` 的子目录。
- **路径**：从根到某个文件/目录的"地址"，用 `\` 连接（Windows）。
  - 绝对路径：`C:\Users\Admin\Desktop\suite\index.html`（从盘符写全）。
  - 相对路径：以"当前所在目录"为起点，如 `suite\index.html`、`..\c\index.html`。
  - `.` 代表当前目录，`..` 代表上一级（父）目录。

### 2.2 什么是后缀（扩展名）

文件名最后一个小点后面的部分叫**扩展名/后缀**，它告诉系统"这是什么类型的文件、
默认用什么程序打开"。例如 `index.html` 的后缀是 `html`，`photo.jpg` 的后缀是 `jpg`。

- 后缀决定图标和默认打开方式，但**不改变文件内容本身**。
- 改后缀不会把图片变成程序；乱改后缀只会让系统不知道用什么打开。
- **安全提醒**：Windows 默认可能"隐藏已知后缀"，于是 `病毒.jpg.exe` 看起来像 `病毒.jpg`。
  务必打开"显示文件扩展名"，看清真实后缀再双击。

**打开显示扩展名：**
- Win11：资源管理器 → 顶部"查看" → "显示" → 勾选"文件扩展名"。
- Win10：资源管理器 → 顶部"查看"选项卡 → 勾选"文件扩展名"。

### 2.3 常见后缀速查

| 后缀 | 类型 | 说明 |
| --- | --- | --- |
| .txt | 纯文本 | 最朴素文字，无格式 |
| .md | Markdown | 带轻量标记的文本（本教程源文件） |
| .html / .css / .js | 网页 | 结构 / 样式 / 脚本 |
| .c / .h | C 源码 / 头文件 | 后面要写的代码 |
| .py | Python 源码 | 另一种语言源码 |
| .exe / .msi | 可执行 / 安装包 | 双击会运行程序，来源不明别乱点 |
| .bat / .cmd | 批处理脚本 | 一串 cmd 命令 |
| .zip / .7z / .rar | 压缩包 | 需解压后用 |
| .jpg / .png / .gif / .svg | 图片 | 照片 / 透明图 / 动图 / 矢量图 |
| .mp3 / .mp4 | 音频 / 视频 | 媒体 |
| .pdf | 便携文档 | 排版固定，适合阅读打印 |
| .docx / .xlsx / .pptx | Office | 文档 / 表格 / 演示 |
| .json / .csv | 数据 | 配置数据 / 表格数据 |
| .lnk | 快捷方式 | 只是"指向"，不是本体 |

> 交互页里有一张"文件资源管理器"卡牌：左边目录树、右边文件列表，
> 点文件能看到它的后缀与类型；用来把"目录—路径—后缀"三件事一次看明白。

## 模块三 · 终端入门：简易 CMD 指令

### 3.1 终端是什么

**终端（命令行）= 用打字代替鼠标点击来指挥电脑。** 你输入一行命令，回车，电脑执行并打印结果。
Windows 上常见的三种"终端外壳"：

- **CMD（命令提示符）**：最老最基础，本课用它入门。
- **PowerShell**：更现代、功能更强，命令略有不同。
- **Git Bash**：装 Git 后自带，模拟 Linux 命令（后面 Git 课用它）。

打开 CMD：`Win + R` → 输入 `cmd` → 回车。

### 3.2 必会基础命令

| 命令 | 作用 | 例子 |
| --- | --- | --- |
| `dir` | 列出当前目录内容 | `dir` |
| `cd 目录` | 进入某目录 | `cd Desktop` |
| `cd ..` | 回上一级 | `cd ..` |
| `cd \` | 回到当前盘根目录 | `cd \` |
| `mkdir 名` | 新建目录 | `mkdir test` |
| `rd 名` | 删除空目录 | `rd test` |
| `del 文件` | 删除文件 | `del a.txt` |
| `copy 源 目标` | 复制文件 | `copy a.txt b.txt` |
| `move 源 目标` | 移动/改名 | `move a.txt d:\` |
| `ren 旧 新` | 重命名 | `ren a.txt b.txt` |
| `type 文件` | 查看文本内容 | `type a.txt` |
| `cls` | 清屏 | `cls` |
| `echo 文字` | 打印一行文字 | `echo hello` |
| `tree` | 树状显示目录 | `tree` |
| `ipconfig` | 看本机 IP 配置 | `ipconfig` |
| `ping 主机` | 测网络连通 | `ping github.com` |

### 3.3 三个好习惯

1. **看清当前目录再操作**：提示符里 `C:\Users\Admin>` 就是"你现在在哪"。删除/移动前先 `dir` 确认。
2. **路径带空格要加引号**：`cd "My Folder"`。
3. **删除类命令不可逆**：`del` / `rd` 删掉不进回收站，敲回车前想清楚。

> 交互页内置一个"模拟 CMD"：可以真的敲 `dir`、`cd`、`mkdir`、`echo` 等命令看效果，
> 在安全沙盒里练，不会动你真实文件。

## 模块四 · GitHub 访问与合法加速

### 4.1 为什么 GitHub 打不开

国内直连 GitHub 常因 DNS 污染/线路质量出现转圈、超时、克隆极慢。这不是你电脑坏了，
是网络链路问题。解决思路两类：**换解析/换节点（改 hosts、改 DNS）** 或 **用本地代理工具择优线路**。

### 4.2 推荐：Watt Toolkit（原 Steam++）

一款**开源、免费**的本地反向代理工具箱（原名 Steam++ / SteamTools），内置 GitHub 加速。
原理是在本机起一个代理，自动挑选当前网络下连接质量最好的节点转发请求，从而正常打开 GitHub。

- 官网：https://steampp.net/
- 开源仓库：https://github.com/BeyondDimension/SteamTools
- 微软商店也可搜 "Watt Toolkit" 安装。

**使用步骤：**
1. 官网下载并安装（或微软商店安装）。
2. 打开软件 → 左侧"网络加速"。
3. 勾选 **GitHub** → 点"一键加速"。
4. 首次可能提示安装/信任一个本地证书，按指引确认（这是本地代理所需）。
5. 浏览器访问 https://github.com 能正常打开即成功；`git clone` 也会变快。
6. 不用时回到软件点"停止加速"即可。

### 4.3 合规与安全边界

- 只用它做**正常访问加速**（GitHub、Steam 社区等），遵守当地法律法规与网站服务条款。
- 不要用来访问违法内容或绕过应有的监管；加速≠法外之地。
- 只从**官网/微软商店/官方 GitHub Releases** 下载，别用来路不明的"破解加速器"。
- 它会在本机装一个根证书用于本地代理；不用时停止加速并可在软件里移除证书。

### 4.4 备选思路（了解即可）

- 改 hosts：把 GitHub 域名指向可用 IP（需定期维护，易失效）。
- 换公共 DNS：如 `223.5.5.5`（阿里）/`119.29.29.29`（腾讯），缓解 DNS 污染。
- 克隆慢可考虑镜像/代理地址，但注意来源可信。
