Before You Code

前导：写代码需要哪些工具

C 语言是嵌入式开发的母语：STM32、RTOS、Linux 内核都以 C 为主。动手之前，先分清三类工具 —— 这是新手最容易混淆的概念。

编辑器 · 稿纸

写代码的地方，本质是「高级记事本」。VSCode 本身不会编译代码，它只负责写和展示。

编译器 · 翻译官

把 .c 源文件翻译成电脑能执行的 .exe。真正干活的是它 —— 本教程选 GCC（MinGW-w64）。

IDE · 精装工作室

编辑器 + 编译器 + 调试器的全家桶。我们用 VSCode + 插件 + MinGW 自行组装一套轻量 IDE。

01

Compiler

编译器选择

编译器平台特点适合谁
GCC（MinGW-w64）✅Windows / Linux开源免费、轻量解压即用，教学与嵌入式主流本教程选择，初学者首选
MSVCWindows微软官方，随 Visual Studio 安装，体积几个 GWindows 桌面软件开发
Clang（LLVM）全平台报错信息友好，macOS 默认进阶可选
为什么选 MinGW-w64：它是 GCC 的 Windows 移植版。后续 STM32 使用的 arm-none-eabi-gcc 与它同属 GCC 家族，命令习惯一脉相承；免费开源、解压即用、不写注册表。

02

VSCode Setup

VSCode 下载与基础配置

Visual Studio Code

code.visualstudio.com · 点击 Download for Windows

打开官网 ↗
  1. 1

    官网下载

    打开 code.visualstudio.com，点击 Download for Windows（或直接访问 /Download 页面）。

  2. 2

    运行安装程序

    建议勾选 「添加到 PATH」 和 「通过 Code 打开」右键菜单，其余保持默认，一路下一步。

  3. 3

    安装中文汉化插件

    点击左侧活动栏「四个小方块」图标（扩展，或 Ctrl+Shift+X），搜索 Chinese，安装：

    Chinese (Simplified) (简体中文) Language Pack for Visual Studio Code

    认准发布者 Microsoft（ID：ms-ceintl.vscode-language-pack-zh-hans），不要装第三方仿冒汉化包。
  4. 4

    右下角重启

    安装完成后右下角弹出提示，点击 「Change Language and Restart」。重启后界面全中文，基础配置部分结束。

网络问题下载不了？

直接问学长要安装包 —— 协会群文件里一般有备用，离线安装效果完全相同。

汉化兜底方案

  • 右下角没弹窗？按 Ctrl+Shift+P 打开命令面板
  • 输入 Configure Display Language，选择 zh-cn
  • 手动重启 VSCode 即可
03

C/C++ Environment

VSCode C/C++ 环境配置

  1. 1

    解压 MinGW 到 VSCode 目录

    下载对应你电脑版本的压缩包，解压到 VSCode 安装目录下，得到 mingw64 文件夹：

    目录结构示例
    D:\Microsoft VS Code\
├── Code.exe
└── mingw64\          ← 解压出来的编译器
    ├── bin\          ← 关键目录，里面有 gcc.exe
    ├── include\
    └── lib\

    打开 mingw64\bin 确认有 gcc.exe、gdb.exe，然后复制 bin 的完整路径（如 D:\Microsoft VS Code\mingw64\bin）。路径不要有中文。

  2. 2

    把 bin 路径配置到系统环境变量

    1. Win 键搜索「编辑系统环境变量」并打开，点击「环境变量」
    2. 在「系统变量」区域找到并双击 Path
    3. 点击「新建」，粘贴 bin 路径，一路「确定」保存
    BASH · 新开终端验证
    gcc --version
gdb --version
两条都输出版本号 = 配置成功
    必须是新开的终端才能读到新的 Path；已打开的终端 / VSCode 请关掉重开。
  3. 3

    安装 C/C++ 插件

    回到扩展页（四个小方块），搜索 C/C++，安装 Microsoft 发布的 C/C++（代码补全、错误提示、调试与运行按钮）。也可装 C/C++ Extension Pack 全家桶，学习阶段基础版即可。

    （可选）安装 Code Runner，获得更简单的「一键运行」体验。环境配置部分结束。

04

Hello World

第一个程序：Hello VSCode

  1. 1

    新建文件夹并打开

    桌面新建文件夹（如 c-study），右键 →「通过 Code 打开」。

  2. 2

    新建 hello.c

    在左侧资源管理器新建文件 hello.c，编写右侧的基础程序并保存。

  3. 3

    点击运行

    点编辑器右上角 ▶ 运行按钮。首次运行若提示选择环境：选 C++ (GDB/LLDB) → gcc.exe 生成和调试活动文件。

  4. 4

    查看输出

    终端正确输出 Hello, VSCode!，基础环境配置完毕。也可手动编译，效果相同：

    BASH
    gcc hello.c -o hello
.\hello.exe

{
    printf("Hello, VSCode!\n");
    return 0;

Optional

可选扩展内容

以下三项不影响基础环境，按需选做。

现象：printf("你好"); 输出变成乱码。原因：源文件是 UTF-8 编码，Windows 终端默认 GBK（代码页 936），两边编码不一致。

BASH · 方案 A / B
chcp 65001  # A：当前终端切 UTF-8（临时）
gcc hello.c -o hello -fexec-charset=GBK  # B：按 GBK 输出

方案 C（推荐）：配合 Code Runner 一劳永逸 —— 设置（Ctrl+,）→ 右上角「打开设置(JSON)」，加入：

settings.json
"code-runner.executorMap": {
    "c": "cd $dir && gcc $fileName -o $fileNameWithoutExt -fexec-charset=GBK && $dir$fileNameWithoutExt"
}
「系统区域设置 → Beta 版 UTF-8」会影响整个系统的老软件，不建议新手使用。

用上一篇教程注册的 GitHub 账号登录 VSCode，开启设置同步：

  1. 点击 VSCode 左下角账户图标（小人像）→「登录以使用设置同步」
  2. 选择 GitHub，浏览器跳转授权页面，点击 Authorize
  3. 回到 VSCode，确认开启 Settings Sync（设置同步）
好处：主题、插件、快捷键、代码片段全部云端备份，换电脑登录同一账号一键恢复；后续还能直接在 VSCode 里克隆、提交、推送 GitHub 仓库，与 Git 教程无缝衔接。
