What is Git

先认识三个概念

Git · 工具

开源的分布式版本控制系统，装在你自己的电脑上。追踪每一次代码变更，随时回滚、并行分支，解决多人协作时代码互相覆盖的问题。

仓库 · 数据的家

存放项目代码与全部历史记录的集合。本地仓库记录你的提交，远程仓库托管在云端，团队通过 Push / Pull 共享代码。

GitHub · 云端的家

基于 Git 的代码托管平台，全球最大的开源社区。让远程仓库有稳定的归宿，并提供 Fork、Pull Request 等协作机制。

Git 是工具 · 仓库 是数据的家 · GitHub 是云端的家 本教程：装好工具 → 建好账号 → 连接两者。
01

Create Account

注册 GitHub 账号

  1. 1

    打开官网

    访问 github.com，点击右上角的 Sign up（注册）。

  2. 2

    填写邮箱

    输入邮箱后点击 Continue。没有其他邮箱可用 QQ 邮箱：你的QQ号@qq.com。

  3. 3

    设置密码

    至少 15 个字符；或至少 8 个字符且同时包含数字和小写字母。建议用密码管理器生成。

  4. 4

    设置用户名

    英文、数字、短横线，简短易记。它会出现在你所有仓库的网址里：github.com/用户名/仓库名。

  5. 5

    验证邮箱

    查收 GitHub 发来的 8 位验证码邮件并填入。收不到先翻垃圾邮件，或点击 Resend 重发。

  6. 6

    人机验证

    完成拼图验证，问卷可跳过。进入个人主页（Dashboard），注册完成。

注册后三件事

  • 开启 2FA：Settings → Password and authentication，用验证器 App 扫码绑定
  • 完善 Profile：头像、昵称、简介，让协作者认识你
  • 习惯英文界面：未来的开发需要一定的英语读写能力

用户名小贴士

  • 注册后虽可修改，但旧链接会失效，尽量一次想好
  • 避免下划线与大小写混排，全小写 + 短横线最稳妥

验证安装

BASH
git --version
git version 2.47.0.windows.1
在文件夹空白处右键 → Git Bash Here 打开终端（Win11 先点「显示更多选项」），输出版本号即安装成功。

其他平台安装

Git Bash 是 Windows 下的类 Unix 终端：既能用 git add、git commit 管理代码，又能用 ls、cd 等 Linux 命令操作文件，是最主流的 Git 命令行方式。按上方步骤安装即可。

方式一：输入 git 命令触发系统安装 Xcode 命令行工具；方式二：用 Homebrew 安装最新版。

BASH
git --version  # 触发系统安装
brew install git  # 或 Homebrew

按发行版选择对应的包管理器命令：

BASH
sudo apt install git   # Debian / Ubuntu
sudo dnf install git   # Fedora
sudo pacman -S git  # Arch
03

Git Config

Git 基础配置

用户名与邮箱 —— 写进每一次提交

BASH
# 用户名：与 GitHub 用户名一致
git config --global user.name "你的用户名"

# 邮箱：与 GitHub 注册邮箱一致
git config --global user.email "你的邮箱"
这两项会记录在你每一次 Git 提交中，与 GitHub 账号保持一致，提交记录才能正确关联到你的头像与主页。
BASH · 检查配置
git config --list  # 查看全部配置
git config user.name   # 单独查看某一项

默认主分支命名为 main

与 GitHub 保持一致，避免 master / main 混用。

BASH
git config --global init.defaultBranch main

行尾自动转换

Windows 检出转 CRLF、提交转 LF；macOS / Linux 把 true 改为 input。

BASH
git config --global core.autocrlf true
04

SSH Key

配置 SSH 密钥连接 GitHub

SSH 密钥是一对文件：私钥留在自己电脑，公钥交给 GitHub。配对成功即证明「你是你」，之后推送、拉取全程免密。

你的电脑
保管私钥 id_ed25519
上传公钥 · 免密验证
GitHub
保存公钥 id_ed25519.pub
  1. 1

    生成 SSH 密钥

    邮箱替换为你的 GitHub 注册邮箱。-t ed25519 是当前推荐算法，比 RSA 更安全、性能更好。执行后连续按 Enter：路径接受默认，密码短语建议留空。

    BASH
    ssh-keygen -t ed25519 -C "你的github注册邮箱"
  2. 2

    启动 ssh-agent 并添加密钥

    让 agent 在后台帮你管理密钥，完成自动认证。

    BASH
    eval "$(ssh-agent -s)"
ssh-add ~/.ssh/id_ed25519
  3. 3

    复制公钥内容

    用 cat 查看后手动复制全部内容（以 ssh-ed25519 开头、邮箱结尾），或直接复制到剪贴板：

    BASH
    clip < ~/.ssh/id_ed25519.pub
  4. 4

    将公钥添加到 GitHub

    头像 → Settings → SSH and GPG keys → New SSH Key：Title 填便于识别的名称（如 My-Work-PC），Key 框粘贴公钥，点击 Add SSH Key 保存。

  5. 5

    验证连接

    首次连接提示确认主机指纹，输入 yes 回车。看到 Hi 开头的欢迎信息即成功：

    BASH
    ssh -T git@github.com
Hi your-username! You've successfully authenticated,
but GitHub does not provide shell access.
    连接超时？可能是网络屏蔽了 22 端口，请看下方「常见问题」第 1 条的 443 端口方案。

Troubleshooting

常见问题排查

连接超时 Connection timed out —— 改用 443 端口
公司内网、校园网的防火墙可能屏蔽 SSH 默认的 22 端口。GitHub 官方提供 443 端口备用方案：
  1. 测试 443 是否可用（注意主机名是 ssh.github.com，不是 github.com）：
BASH · 第一步
ssh -T -p 443 git@ssh.github.com
  1. 创建 / 编辑 ~/.ssh/config 文件（无扩展名，已有内容则在末尾追加）：
~/.ssh/config · 第二步
Host github.com
    Hostname ssh.github.com
    Port 443
    User git
  1. 再次验证，之后所有 SSH 操作自动走 443 端口：
BASH · 第三步
ssh -T git@github.com
Permission denied (publickey)
  1. 执行 ssh-add -l 查看 agent 中的密钥；为空则执行 ssh-add ~/.ssh/id_ed25519 重新添加。
  2. 确认 GitHub 上粘贴的是 .pub 公钥的完整内容（以 ssh-ed25519 开头），不要粘贴私钥。
  3. 一台电脑一对密钥即可；多台电脑各自生成、各自添加。
'git' 不是内部或外部命令
  1. 多为安装时 PATH 选项未选对：重新运行安装程序，选择中间项（Git from the command line and also from 3rd-party software），或直接重装保持默认。
  2. 安装后需重启终端 / VSCode，新的 PATH 才会生效。
HTTPS 和 SSH 地址怎么选？
推荐 SSH（git@github.com:用户名/仓库.git）：配好密钥后全程免密。HTTPS 地址则配合 Git Credential Manager 记住凭据。注意：GitHub 自 2021 年起不再支持账号密码推送，HTTPS 方式需以 Personal Access Token（PAT）代替密码。
收不到 GitHub 验证码邮件
  1. 检查垃圾邮件 / 订阅邮件分类。
  2. 在注册页面点击 Resend 重新发送。
  3. QQ 邮箱可在「自助查询」中查看是否被系统拦截。
