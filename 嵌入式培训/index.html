About / 关于电控组培训

从这里开始

零基础起步

不需要任何编程基础。从注册账号、装好工具开始，一步步带你写出第一个程序，走进开发的世界。

动手实践

每个知识点都配可运行的代码与交互演示。代码要亲手敲一遍，报错先读提示信息，实践出真知。

循序渐进

按 Git → VSCode → C 语言 → 单片机 的顺序推进，打牢语言基础后再进阶硬件，把代码烧进真实电路。
